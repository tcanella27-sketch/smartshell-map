# 🗺️ Интерактивная карта компьютерного клуба SmartShell

Локальное информационное табло для второго монитора администратора. Автоматически подтягивает сетку зала, отображает статусы компьютеров (свободен/занят) в реальном времени и выводит текущие бронирования со значком замка прямо из SmartShell API.

## 🚀 Инструкция по установке на новом компьютере

Выполните эти простые шаги один раз для первоначальной настройки проекта:

### Шаг 1. Скачивание проекта через CMD (Обязательно для работы автообновлений)
1. Откройте командную строку (CMD) от имени администратора и установите Git:
   ```bash
   winget install --id Git.Git -e --source winget
   ```
   *После установки обязательно закройте окно CMD и откройте его заново.*
2. Перейдите на диск `C:\` и скачайте репозиторий:
   ```bash
   cd C:\
   git clone https://github.com
   ```

### Шаг 2. Установка Node.js и библиотек
3. Перейдите в папку установки внутри скачанного проекта:
   ```bash
   cd smartshell-map\installation
   ```
4. Запустите файл `install_node.bat` от имени администратора (или установите вручную через идущий в комплекте `node-v24.13.0-x64.msi`).

**Далее всё выполняем строго через командную строку (CMD):**

5. Перейдите в корень проекта к файлу `server.js` (поднимаемся из папки `installation` на уровень выше):
   ```bash
   cd ..
   ```
   *(Если вы открыли новое окно CMD, просто пропишите путь до папки, например: `cd C:\smartshell-map`)*

6. В первый раз запускаем установку необходимых библиотек:
   ```bash
   npm install @xlsft/smartshell-sdk
   npm install express
   ```

7. **Настройте доступы:** Откройте файл `smartshell.js` и укажите ваш реальный пароль, логин (телефон) и `company_id` от админки клуба.

## 💻 Использование

* **`start.bat`** — дважды кликните по этому файлу для запуска проекта. Он запустит сервер бэкенда и автоматически откроет карту в вашем браузере по адресу `http://localhost:3000`.
* **`update.bat`** — дважды кликните по этому файлу, чтобы мгновенно накатить любые обновления кода, которые вы загрузите на GitHub в будущем. Скрипт сам сбросит кэш, скачает свежий код и обновит Node-пакеты.
